# 🌱 Codigo Arduino para Huerto Ibero

Sistema inteligente de monitoreo y automatización de un huerto utilizando ESP32.

## Características

- Medición de humedad del suelo
- Temperatura y humedad ambiental
- Calidad del aire
- Cámara ESP32
- Control automático de riego
- Dashboard web

## Hardware utilizado

- ESP32
- Sensor BME688
- Sensor humedad de suelo
- PMS5003
- Cámara ESP32
- Electroválvula 12V

## Arquitectura

ESP32 → API Flask → Dashboard
